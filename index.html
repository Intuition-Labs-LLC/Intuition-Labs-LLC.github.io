Intuition Labs · the foundry

One mechanism, everywhere. Take many small readings of the same thing. Measure how much they agree — one number, R, from 0 to 1. Compare R to a threshold τ. Then commit, escalate, skip, or vent — and leave a receipt. The field above is that loop as physics: 576 phase oscillators coupled to their neighbours, ordering until R crosses 0.9 and the field crystallises. Every package below is the same loop in a different basis.

A companion to, not a competitor of, jacobian-lens. Intuition Labs is independent and not affiliated with Anthropic; we externalize ideas from their published paper (Gurnee, Sofroniew et al., Transformer Circuits 2026) and cite them — no code was copied.

The applicability layer. Gate with jspace; execute on interaction nets. The DRM compiler family (py2bend / skill2bend / tools2bend) lowers Python, skills, and MCP tool schemas to Bend and reduces them on HVM — the machine is real and entirely in C. Measure here; run fast there.
